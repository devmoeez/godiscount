# Part A & B: The 3 Screens (Golden Path)

The table below summarises the three interconnected wireframe screens selected for the clickable Figma prototype.

| **Screen** | **Screen Name**  | **User Goal**                    | **Key Action**               |
|------------|------------------|----------------------------------|------------------------------|
| **1**      | Home Dashboard   | Discover AI-curated deals nearby | Tap Scan Deal or a deal card |
| **2**      | Scan & Save (AR) | Scan a product to compare prices | Tap View All Offers          |
| **3**      | Deal Details     | Review deal info and get it      | Tap Get This Deal            |

# Part C: UX Rationale (100-word Summary)

## 1. What is the Golden Path?

The Golden Path is the single most important user journey in GoDiscount AI's MVP, the path a new user takes to get their first real value from the app in under 60 seconds:

> **Step 1: Home Dashboard:** The user opens the app and immediately sees AI-recommended deals near their location (Lahore). A prominent 'Scan Deal' button and hyperlocal deal cards invite action.
>
> **Step 2: Scan & Save (AR Scanner):** The user points their camera at any product or menu item. The AI instantly scans it and surfaces a ranked price comparison across nearby stores and delivery apps (Naheed, Daraz, Foodpanda).
>
> **Step 3: Deal Details:** The user reviews the full deal: verified by AI, with validity date, timings, price comparison across platforms: and redeems it with one tap ('Get This Deal').

## 2. Why this simple layout over a complex design?

Our group chose this focused, minimal layout for four reasons:

- Lowest friction to value: A new user in Pakistan wants to save money in the next five minutes, not learn a complex app. Three screens deliver that promise without unnecessary steps.

- MVP scope discipline: The Figma assignment requires exactly 3 screens. Choosing the Home → Scan → Deal path covers GoDiscount AI's most differentiated feature (AR price scanning) while staying within scope.

- Cognitive load: Low-fidelity wireframes with clean card-based layouts reduce visual noise, making it easier for evaluators and stakeholders to focus on the flow logic rather than aesthetics.

- Testability: This path is easy to user-test with a click-through prototype. We can measure time-to-first-deal-redemption as a single, meaningful metric for MVP validation.

# Figma Prototype: Build Checklist

Use this checklist when replicating this Golden Path in Figma:

- Create a new Figma file and set frame size to iPhone 14 Pro (393 × 852 px)

- Design 3 frames: (1) Home Dashboard, (2) Scan & Save, (3) Deal Details

- Use GoDiscount AI brand colors: Primary \#5346D4, Accent \#22C87A, Warning \#FFC83D

- Keep fidelity LOW, boxes, labels, placeholder icons only (no real photos needed)

- Add prototype links:

  - Home 'Scan Deal' button → Screen 2

  - Home deal card tap → Screen 3

  - Scan 'View All Offers' button → Screen 3

  - Screen 3 back arrow → Screen 2

  - Screen 2 back arrow → Screen 1

- Set prototype trigger to 'On Click' and transition to 'Instant' or 'Slide'

- Share via Figma 'Share Prototype' link (ensure viewer access is ON)

- Include the 100-word UX Rationale in the Figma cover page or description
